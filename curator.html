Curator's Console

Library review, groups & episodes, the conversion queue, and invites — runs entirely in this browser tab
The key is held in this tab's memory only — never written to disk, never sent anywhere but the gate. Closing the tab forgets it.
Scan folder
Rescans the Da Moveesh folder and adds any new files to the library. Also run this after deleting a movie.
Library review
Duplicate titles, files with no fetched metadata, and visible films with no subtitles. Files with no metadata stay off the site until you fix them, whitelist them, or exclude them.
Current decisions
Every exclude, group and whitelist made from this dashboard, in one place. Nothing here ever touches Da Moveesh — undo anything below and it's back on the site immediately. Click Manage on a group to reorder episodes, correct a mis-tagged one, or link its real series for OMDb lookups.
The worker never runs on its own
Transform queues a file here — a row in the database, nothing more. Nothing is converted until you start the worker yourself: 
docker compose up worker
It drains whatever's queued below and exits on its own — no folder watching, no library-wide scanning.
Needs conversion
Files that would fall back to a live transcode instead of playing directly in a browser — read from Jellyfin's own analysis, nothing probed here.
